# Quiet Nodes — Web Novel

A self-contained web novel set in 2085 after the Quiet Collapse.

## To Publish

1. Upload the entire `artifacts` folder (or at least `index.html` + the `imagine_images/` directory) to any static host:
   - GitHub Pages
   - Netlify
   - Vercel
   - Cloudflare Pages
   - Any web server

2. Open `index.html` in a browser. All images are relative and local.

## Structure

- Single HTML file with embedded CSS
- Sticky navigation
- Sequential chapters with full-page comic panels
- Dark, readable theme suited to the setting

## Chapters

1. The Cascade
2. Maya’s Role
3. The Silence Keepers
4. Fallout (including the self-driving mandate)
5. River Cache
6. The New Currency
7. 2085 (present action)

Built from the full story threads developed in conversation.
